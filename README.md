# Kabir Rana — Portfolio (React Replica)

Inspired by the layout, motion and colour language of a Framer portfolio template (portavia.framer.website). Rebuilt from scratch with original copy, imagery and code using React + Vite + Tailwind CSS + Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build for Production

```bash
npm run build
```

## Deploy to Vercel

### Option 1 — Vercel CLI
```bash
npm install -g vercel
vercel
```

### Option 2 — GitHub + Vercel Dashboard
1. Push this project to a GitHub repo
2. Go to https://vercel.com/new
3. Import your repo
4. Framework preset: **Vite**
5. Click **Deploy** — done!

## What's inside
- Pill navbar with slide-down entrance
- Split hero with floating badge animation
- Accordion services section with checklist reveal
- Animated stat counters in the About section
- Featured project cards with hover zoom + category/arrow overlay
- Bento-style testimonials grid mixing quotes and stat cards
- FAQ accordion
- Blog preview grid
- Contact form with staggered field entrance
- `/about`, `/projects`, `/blogs` routes via React Router

## Tech Stack
- React 18
- Vite 5
- Tailwind CSS 3
- Framer Motion
- Lucide React
- React Router
